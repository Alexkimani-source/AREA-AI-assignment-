# Assignment 1: Personal Profile
Objective:To understand variables and basic data storage in Python.

Task: Create variables for your name, age, state of residence, and favorite AI tool. Print them in a readable format.

Expected Learning Outcome: Students will understand how to store and display data using variables.
# Assignment 2: Data Types Practice
Objective: To identify and work with different Python data types.

Task: Create variables for string, integer, float, boolean, list (5 AI tools),tuple and a dictionary. Print values and their types.

Expected Learning Outcome: Students will understand Python data types and how to check them.
